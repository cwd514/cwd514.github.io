1一般説明GENERAL DESCRIPTION

手元の 1 台で、自分が持っている以上の大きさのモデルを動かす。そのために何を変え、どの数字がどう動いたかの記録です。GPU は 8 GB しかありません。対象のモデルは 21.1 GB あります。重みは 4 bit に畳まれ、入りきらない分は CPU に残したまま、それでも 131,072 トークンの文脈が確保されました。

ここに載っている数字はすべて、この 1 台で実際に測ったものです。測っていない欄は空けてあります。曲線は実測点の間を補間していません。

3実測特性MEASURED CHARACTERISTICS

Qwen3.8-27B（2026-09-28 計測）。横軸は文脈長、縦軸は実測値。線は実測点を結んだだけで、その間は測っていません。灰色の破線は、値が無いまま終わる区間です。補間した曲線は引いていません。

  1. 縦軸はいずれも 0 起点。目盛りを省いていません。
  2. 線は実測点を結んだだけで、その区間の値ではありません。灰色の破線は、値が無いまま終わる区間を示します。
  3. IQ2_XS の 131,072 は ngl 32 と 36 の 2 回とも文脈を確保できず終了（rc=-6 は CUDA error / rc=1 は context を作れず）。値が無いので点も線もありません。これより低い ngl は試していません。
  4. ピーク VRAM は prefill と decode の測定値の高い方です。

4構成ラダー131k CONFIGURATION LADDER

Qwen3.6-35B-A3B / qwen36-35b-q4km-r2.gguf（21.1 GB, Q4_K_M, 733 tensors）。このモデルは 40 層あります（同じヘッダの qwen35moe.block_count = 40）。2026-09-21 計測。重みは 4 bit のまま、KV は q8_0、flash-attn は on。130k 文脈で初回トークンが出るまでの時間を、構成を変えながら詰めていった記録です。

5量子化スイープQUANTIZATION SWEEP DATA

Qwen3.8-27B を 2 つの量子化で、文脈長を 8,192 から 131,072 まで振った実測値（2026-09-28）。このモデルは 64 層あります（量子化ファイルのヘッダの qwen35.block_count = 64）。ngl は「GPU に載せた層数」なので、分母はどちらも 64 です。IQ3_S は 8,192 で 32 層、131,072 で 20 層。IQ2_XS は 8,192 で 48 層、65,536 で 40 層、131,072 は ngl 36 と 32 を試してどちらも確保できず、これより低い ngl は試していません。量子化が違えば載る層数も違います。同じ量子化の中では、VRAM が足りなくなるたびに自動で下げています。この表の数値が、上の 3 つの図の元データです。

読み取れること — 軽い量子化（IQ2_XS）は速いが、131,072 では ngl を 36、32 と下げても文脈を確保できず、掃引はそこで止まりました。重い量子化（IQ3_S）は遅い代わりに、131,072 でも 6,944 MiB に収まっています。131,072 を実際に測れたのは IQ3_S だけで、この 2 つを同時に取った測定はありません。IQ2_XS の 131,072 はこれより低い ngl を試していないので、動くかどうかは分かっていません。どちらを選ぶかは、その日そのモデルで何をしたいかで決まります。

  1. 本書の数値はすべて、記載した 1 台で実際に測定したものです。他の環境での値を保証しません。
  2. 空欄（—）は元の記録でも未計測です。推定値で埋めていません。

  7. 131,072 トークンの文脈は確保できましたが、その長さで品質が保たれるかは測っていません。thinking が正常に回ることは確認しています。
