# ローカル推論 実測記録

GPU 8 GB の 1 台で 131,072 トークンの文脈を動かすまでに、何を変えて、どの数字がどう動いたかの記録。
半導体のデータシートの体裁を借りて書いてあります。

依存ゼロの静的サイトです。ビルドも `node_modules` も `package.json` もありません。
外部への通信は **0 本**。CDN・解析・外部フォントのいずれも読みません。ページを開いたときの
リクエストは 7 本（HTML・CSS・JS・書体 4 面）で、すべて自分のホストの中身です。
<link rel="preload"> は `hack-700` の `@font-face` と同じ 1 本にまとまるので、本数は増えません。
favicon は SVG を data URI で HTML の中に置いてあり、取りに行きません。

## 見る

```sh
tools/serve.sh            # → http://127.0.0.1:8129/
```

`index.html` を直接開いても概ね動きますが、AVIF / WebP / WOFF2 に正しい `Content-Type` を
返させるために上のサーバを使ってください。`file://` でも表示は崩れません。

## 置いてあるもの

```
index.html            本文。測定値はすべてここ（表と data-*）に一度だけ書いてあります
css/styles.css        紙・インク・朱・青の 4 役。明暗は反転印刷として同じ幾何で入れ替わります
js/main.js            動作点レールの操作。数値は DOM から読み、JS 側には複製を持ちません
assets/fonts/         自前で同梱した書体 4 面（WOFF2）と、そのライセンス全文
assets/img/           禅ドライブの実レンダリング 4 枚（AVIF + WebP）と OG カード
tools/                撮る・確かめる・作り直す・公開するための道具
PRODUCT.md            何を作っているのかの記録（Impeccable の product truth）
```

## 数字の扱い

この作品でいちばん気をつけているのは、**測っていない数字を出さない**ことです。

- 測定値は HTML に一度だけ書きます。`js/main.js` は `#sweep-table` の行と `.rating` の
  `data-*` を読むだけで、数値の複製を持ちません。
- 折れ線は実測点を結びますが、**間を補間しません**。値が無いまま終わる区間は灰色の破線で示し、
  本文でもそう書いています。
- 空欄は空欄のまま（`—`）にします。
- 読み出しの数字は、スライダを動かしても **実測点の値へ即座に飛びます**。間を補間すると
  `ngl 20 → 28` が 21…27 を通ってしまい、測っていない値を印刷することになるからです。
  380 ms の慣性は、針（カーソル）の側にだけ持たせています。
- グラフのカーソルは実測点の上にしか止まりません。

測定は 2 系統あり、**混ぜていません**。どちらも別のモデルの、別の日の測定です。

| | 対象 | 層数 | 何を測ったか |
|---|---|---|---|
| A | Qwen3.6-35B-A3B（21.1 GB, Q4_K_M） | 40 | 131k 文脈を成立させる構成ラダー |
| B | Qwen3.8-27B（IQ3_S / IQ2_XS） | 64 | 量子化 × 文脈長のスイープ |

層数は量子化ファイルのヘッダから読みます（`qwen35moe.block_count` / `qwen35.block_count`）。
`ngl` は「GPU に載せた層数」なので、分母が無いと読めません。B は 64 層で、量子化ごとに別の系列です。
IQ3_S は 8,192 で 32 層、131,072 で 20 層。IQ2_XS は 8,192 で 48 層、65,536 で 40 層、
131,072 は ngl 36 と 32 を試してどちらも確保できず、これより下は試していません。**量子化をまたいで 1 本の系列としては読みません。**
**層は載るか載らないかの二択でもありません。**
`-ngl` は attention を GPU に、`--n-cpu-moe` は expert を CPU に置くので、1 層の中が分かれます。
だから「この層は GPU」と塗る図は作りません。記録にあるのは 2 つの軸の**数**であって、割り当てではありません。

A と B を並べて比べる書き方はしていません。比べられる形で測っていないからです。
「主要特性」のような 1 つの表に両方が並ぶ場所では、**どの行も自分のモデル名を名乗ります**。

## 確かめる

```sh
tools/serve.sh &
node tools/verify.mjs http://127.0.0.1:8129/
```

見ているもの:

1. 外部リクエストが 0 か（自ホスト以外への通信を全部挙げます）
2. コンソールエラー
3. 画像が実体として読めているか
4. コントラスト（明・暗の両方で WCAG AA）
5. 320 / 390 / 768 / 1024 / 1440 / 1920 px で横に溢れないか
6. 当たり判定が 44×44 以上か
7. 動作点レールの読み出しが、表の値と全 9 通りで一致するか
8. JavaScript を切っても本文と主要な数字が読めるか
9. Tab で辿れるか、スキップリンクがあるか

文字の大きさは目視ではなく実測で見ます。SVG の中の文字は `viewBox` の倍率がかかるので、
静的な解析だけでは実際の描画寸法が分かりません。

```sh
node tools/measure.mjs http://127.0.0.1:8129/ 390
```

「数字は補間しない」という約束も、コードではなく時系列で確かめます。スライダを動かした直後の
各フレームで読み出しの文字列と針の位置を記録し、間に現れた値を数えます。

```sh
node tools/prove-snap.mjs http://127.0.0.1:8129/
```

実測: 文字列は **0 ms** で最終値、針は **367〜384 ms**（1 回の測定では決まらない。幅がある）、間に観測された文字列は **0 個**。

## 書体

本文の日本語は端末のゴシック体に任せています。同じ文字集合を Noto Sans CJK JP から
切り出すと実測 **89,268 B（87.2 KB）** でした。`tools/cjk-subset-size.py` がその 1 本です。
同梱中のラテン 4 書体（73,272 B）の 1.2 倍を、読者の端末が既に持っている書体のために
積むことになるので、積んでいません。

ラテン側の 2 役だけ、自前で同梱しています。`tools/subset-fonts.py` が `index.html`・`js/main.js`・
`css/styles.css` から実際に使われている文字を集めて切り出します。

| 役 | 書体 | 面 |
|---|---|---|
| 数値・測定値・刻印 | **Hack**（MIT） | 400 / 700 |
| 大文字ラテンの見出し・ラベル | **DejaVu Sans Condensed**（Bitstream Vera） | 400 / 700 |

4 面で 73,272 B。どちらもライセンス全文を `assets/fonts/` に同居させています。
作り直すには fontTools が要ります（端末に無ければ `.impeccable/py` へ入れます）。

```sh
PYTHONPATH=.impeccable/py python3 tools/subset-fonts.py
```

## 画像を作り直す

原板は禅ドライブ（別リポジトリ）の実レンダリング PNG（1280×720）です。

```sh
tools/optimize-images.sh [原板のディレクトリ]     # 既定 ~/Documents/drive/shots
```

880px 幅へ lanczos で落としてから WebP（`-q:v 80`）と AVIF（`-q 62`）を作り、
その場で両方がデコードできることを確かめます。板 8 ファイルで 79,649 B。

OG カードは `tools/og.html` を headless Chromium で描いたものです。

```sh
node tools/make-og.mjs 8129
```

**すべての画像に来歴が付いています。** 板は `impeccable embed-prompt` で、
OG カードは上のコマンドが、それぞれ `*.json` を書き残します。何から作ったか辿れない画像は置きません。

## 公開する

**このリポジトリの根は、そのまま公開できる形になっていません。**
`PRODUCT.md` には「出さない」一覧と、本人が名指しで触れるなと言った団体名が入っています。
`.impeccable/` には指示契約・ロール・判断の記録が丸ごと入っています。

```sh
tools/stage.sh            # → dist/
```

`index.html` `css/` `js/` `assets/` だけを複製し、複製した中に公開しない文字列が残っていれば
そこで失敗します。`dist/` をそのまま `https://cwd514.github.io/` の中身にしてください。

控えではなく **`dist/` そのもの**を別のポートで配って `tools/verify.mjs` を通してあります。
作業ツリーで通って複製で落ちる、ということがないようにするためです。

## 支えているもの

- **紙 / インク / 朱 / 青** の 4 役だけ。朱は定格を超えた印に、青は実測値にしか使いません。
- 角丸・影・グラデーションはありません。面は罫線と余白で区切ります。
- 明暗は反転印刷です。暗い側でも幾何は同じで、トークンだけが入れ替わります。
- `prefers-reduced-motion` を尊重します。切ってあれば数値は即座に確定します。
- 目次・連絡先・摺動子・スイッチはすべて 44×44 以上の当たり判定を持ちます。
  狭い画面では目次が折り返し、10 節すべてが指で届きます。
- 本文と表の文字の下限は 11px で、`--t-lat` / `--t-jp` の 2 つのトークンに集めてあります。
  図の中の目盛りはこれとは別で、SVG が欄の幅に合わせて縮むぶんだけ小さくなります。390px では軸の数字が **8.68px**（`9.5px` × 倍率 0.913）、定格の見出しが 9.13px です。1440px と 768px では倍率が 1 を超えるので、11px を割る文字は 0 件です。軸の数字はすぐ下の表と同じ値で、図には `aria` の説明も付いています。

## 出していないもの

`PRODUCT.md` の「出さない」一覧に従い、非公開の作業名・内部ツール名・コミュニティの名前は
本文にもコードにもコメントにも `data-*` にも書いていません。方向性の契約（THESIS などの 6 ブロック）も
内部の作業メモであり、出荷物には一切含まれていません。

## 動作環境

Node は `tools/` の確認用スクリプトにしか使いません（`verify.mjs`, `shot.mjs`, `cdp.mjs`,
`measure.mjs`, `prove-snap.mjs`, `capture-review.mjs`, `make-og.mjs`。いずれも依存ゼロで、
Node 内蔵の `WebSocket` で CDP に直接つなぎます）。サイト本体は HTML / CSS / JS だけです。

画像の作り直しに `ffmpeg` と `avifenc`、書体の切り出しに `fontTools` を使います。
